# Code of conduct

Be kind, be direct, assume good faith. Disagree with the code, not the person. No harassment,
no discrimination, no publishing of other people's private information (and in this project,
no posting of anyone's trail). Maintainers may remove, edit or reject contributions and comments
that do not follow this, and may ban repeat offenders.

Report a problem to the maintainer listed in `pyproject.toml` or through a private GitHub
security advisory; reports are handled in confidence.

Adapted from the Contributor Covenant, version 2.1, in short form.
